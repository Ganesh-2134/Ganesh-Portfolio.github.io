# Ganesh M Portfolio

Professional portfolio for Ganesh M, AWS DevOps Engineer. It is a dependency-free static site suitable for GitHub Pages.

## Publish on GitHub Pages

1. Create a public GitHub repository named `Ganesh-2134.github.io`.
2. Upload or push these files to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch** / `main` / `/(root)`.
4. GitHub will publish the site at `https://ganesh-2134.github.io/` within a few minutes.

For a project repository instead, GitHub Pages will use `https://ganesh-2134.github.io/<repository-name>/`.
